# License Plate Recognition System

Projet en cours de développement : système de reconnaissance de plaques d'immatriculation en Python.

## État actuel
- Extraction de région d'intérêt (ROI) et binarisation
- Dataset synthétique généré avec PIL
- Classification par SVM (scikit-image / scikit-learn)

## À venir
- Amélioration de la robustesse sur images réelles
- Évaluation quantitative (accuracy, matrice de confusion)

## Stack
Python, scikit-image, scikit-learn (SVM), PIL
